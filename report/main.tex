% The report. This is where a measurement becomes a claim, which is the step at
% which this project's characteristic failure -- a wrong belief -- actually
% happens. Every number that reaches this document has left the record that
% carried its conditions with it. See claims-verified.md, beside this file, for
% the pass that checks it back against source, and read that file's header
% BEFORE writing prose rather than after.
%
% PROSE IS DRAFTED IN MARKDOWN, COMMITTED, AND TYPESET SEPARATELY, WITH BOTH
% COMMITTED SO THE TRANSLATION IS DIFFABLE. Keep draft.md beside this file.
%
% draft.md IS TRACKED. Not a scratch file, not gitignored, not kept on one
% machine -- committed, and committed in the same pull request as the .tex it was
% typeset into. UNTRACKED, THE DIFF HAS NOTHING TO COMPARE AGAINST AND THE
% PRACTICE IS DECORATIVE: the whole value is that two revisions of the prose sit
% in the history side by side, so that the sentence which changed on its way into
% LaTeX is visible as a change rather than as a fact.
%
% None ships here, deliberately -- an empty draft.md would be a file teaching
% nothing. Create it with the first paragraph of real prose.
%
% This is what made claim verification possible in the instance this template
% came from. Two things follow from it, and they are the reason it is a practice
% rather than a preference:
%
%   1. Claims are checked against the record while the prose is still CHEAP TO
%      MOVE. A paragraph that has to be re-typeset to be corrected is a paragraph
%      whose correction gets argued about.
%   2. THE DIFF BETWEEN DRAFT AND TYPESET OUTPUT IS WHERE A MANGLED NUMBER SHOWS.
%      A figure that changes in translation -- a dropped qualifier, a transposed
%      digit, a scope clause that did not survive being turned into a sentence --
%      is invisible in either document alone and obvious between them.
%
% Build:  make -C report        (or: latexmk -pdf main.tex, from this directory)
%
% IT COMPILES AS SHIPPED, deliberately: a scaffold whose build is broken on day
% one teaches you to ignore the build.

\documentclass[11pt]{article}

% Standard margins, stated rather than defaulted, because figures are sized
% against \textwidth. At letterpaper with 1 in margins \textwidth is exactly
% 6.5 in, which is the width report/figures/README.md asks figure scripts to draw
% to, so a figure included at width=\textwidth is reproduced 1:1 and its type is
% not rescaled.
\usepackage[letterpaper,margin=1in]{geometry}

\usepackage[T1]{fontenc}
\usepackage{lmodern}
\usepackage{graphicx}
\usepackage{booktabs}
\usepackage[hidelinks]{hyperref}

% biblatex + biber, not bibtex. biblatex is what carries per-entry provenance
% notes -- including a software entry pinned to a COMMIT rather than to a branch,
% which is the only citation form that means anything for a repository.
\usepackage[backend=biber,style=numeric,sorting=none]{biblatex}
\addbibresource{refs.bib}

\graphicspath{{figures/}}

\title{TITLE}

% AUTHORSHIP IS A CLAIM LIKE ANY OTHER. If an AI collaborator did work that
% appears here, say what it did and where, rather than leaving the reader to
% infer it. The instance this template came from named its collaborator on the
% byline with a footnote pointing at an appendix that described what each surface
% actually did. Adopt that, or decide otherwise deliberately -- but decide.
\author{
  AUTHOR \\
  \normalsize AFFILIATION
}

\date{\today}
